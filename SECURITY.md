# Security Policy

## Supported version

Zhang Lab supports the latest internal release. Version `0.1.0` is ad-hoc
signed and not notarized; that distribution limitation is not a security
signature from Apple.

## Report a vulnerability

Use the private repository's
[Security Advisories](https://github.com/Hongjiseung-ROK/chemsmart-studio/security/advisories/new)
page. If the problem is not sensitive, use a private
[GitHub Issue](https://github.com/Hongjiseung-ROK/chemsmart-studio/issues/new).

Include the affected version, reproducible steps, impact, and any suggested
mitigation. Do not attach credentials, authorization headers, private model
payloads, socket secrets, unpublished structures, or raw researcher paths.

## Disclosure

Zhang Lab uses coordinated disclosure. A vulnerability is disclosed only after
affected internal users have a fix or mitigation. Reporter credit is provided
on request.
